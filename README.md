# Basic Keylogger Using Python

## 📌 Project Overview
This project is a simple keylogger developed using Python.

The program records keyboard keystrokes and saves them into a text file. It demonstrates keyboard event handling and file operations in Python.

This project is developed only for educational and ethical cybersecurity learning purposes.

---

# 🚀 Features
- Records keyboard keystrokes
- Saves logs into a text file
- Detects normal and special keys
- Simple and beginner-friendly
- Stops safely using ESC key

---

# 🛠 Technologies Used
- Python
- pynput library
